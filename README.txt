مجمع مصائب أهل البيت - نسخة جديدة
1) ارفع كل محتويات هذا المجلد إلى مستودع GitHub (وليس ملف ZIP نفسه).
2) فعّل Settings > Pages > Deploy from branch > main > /(root).
3) افتح رابط GitHub Pages الناتج من الهاتف.
4) يمكن تقليب الصفحات بالسحب، التكبير والتصغير، الانتقال لرقم صفحة، وحفظ ملاحظة على الجهاز.
5) البحث بالكلمات يعمل إذا كان ملف PDF يحتوي نصاً. الكتب المرفوعة حالياً قد تكون صفحات مصوّرة؛ عندها يلزم OCR لإضافة بحث حقيقي داخل الكلمات.
